# ChessWithQuests

Chess game engine with quest mechanics, rule enforcement, player profiles, and 100% autogenerated documentation from Python docstrings.

---

## Overview

ChessWithQuests extends standard chess with an objective-based quest system, timing controls, and player profile tracking. All application modules and classes are documented directly from source code annotations and Google-style docstrings.

## Architecture & Modules

The codebase is organized into three primary layers:

### 1. Controllers (`src/controller/`)
Application controllers coordinate user interactions, GUI lifecycles, turn execution, and timer updates.
- **`controller.controller`**: Core game controller orchestrating board state, move execution, turn switching, and alerts.
- **`controller.window_controller`**: GUI controller managing window events, square clicks, dialogs, timers, and notifications.

### 2. Model Domain (`src/model/`)
The core domain model is separated into focused subpackages:
- **Game Domain (`src/model/game/`)**:
  - `board`: 8x8 chessboard representation, piece placement, and square indexing.
  - `manager`: High-level game coordinator managing turn order, clocks, and match states.
  - `validator`: Move validation, check detection, checkmate, and stalemate verification.
  - `move`: Atomic move records with capture flags, check statuses, and promotions.
  - `player`: Player state, active timers, and linked user profiles.
  - `quest`: In-game objectives rewarding experience upon condition satisfaction.
  - `timer`: Countdown timers with per-move increments and timeout triggers.
  - `logger`: Structured logging for moves, board states, and game events.
- **Pieces (`src/model/pieces/`)**:
  - `piece`: Base piece class with movement vectors, leaping rules, and color encapsulation.
  - `pawn`: Single/double forward moves, diagonal captures, and promotion triggers.
  - `rook` / `tower`: Orthogonal sliding moves and castling eligibility.
  - `horse`: L-shaped leaping vectors.
  - `bishop`: Diagonal sliding rays.
  - `queen`: Combined orthogonal and diagonal rays.
  - `king`: 1-square omnidirectional moves, check avoidance, and castling logic.
- **Users (`src/model/users/`)**:
  - `user`: Persistent player profile with experience points, levels, and completed quests.
  - `manager`: User registration, profile persistence, and move execution tracking.
- **Miscellaneous (`src/model/misc/`)**:
  - `notation`: Coordinate notation conversions (algebraic, stenographic).
  - `export_writers`: Game notation exporters (PGN and stenographic formats).
  - `quest_manager`: Quest registration, verification against game events, and rewards.
  - `metadata`: Game and player metadata representations.

### 3. Views (`src/view/`)
User interface view components rendering the chessboard, pieces, clocks, and user profile dialogs.
